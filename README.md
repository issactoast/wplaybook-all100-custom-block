# WPlaybook All100 Custom Block

버튼을 예쁘게 반짝이게 만들어주는 아주 간단한 워드프레스 플러그인입니다. 버튼에 `wplaybook-button` 클래스만 추가해 주시면 됩니다!

## Description (플러그인 소개)

이 플러그인은 가볍고 최적화된 CSS 파일을 워드프레스 사이트에 로드해 줍니다. 
해당 코드는 `wplaybook-button` 이라는 클래스가 추가된 어떤 요소(버튼, 링크 등)든 살아 숨 쉬는 듯한 예쁜 반짝임(Shimmer) 애니메이션을 부여해 줍니다.

💡 **워플 올백 애드온 커스텀 블록 구매하기:** 
[https://community.wplaybook.com/products/all100-reborn-add-on/](https://community.wplaybook.com/products/all100-reborn-add-on/)

## Installation (설치 방법)

1. 우측의 깃허브 코드 다운로드(.zip)를 받으시거나, 릴리즈 탭에서 플러그인 `.zip` 설치 파일을 다운로드합니다.
2. 워드프레스 관리자 홈페이지에 로그인한 뒤, **[플러그인]** -> **[새로 추가]** 메뉴로 이동합니다.
3. **[플러그인 업로드]** 버튼을 누르고 다운받은 `.zip` 파일을 선택하여 설치 및 **[활성화]** 시켜줍니다.
4. 이제부터 원하시는 어떤 요소든 `wplaybook-button` 클래스만 넣어주시면 효과가 적용됩니다!

## Frequently Asked Questions (자주 묻는 질문)

### 반짝이는 효과는 어떻게 적용하나요?

워드프레스의 어떤 위젯이나 블록이든, HTML의 클래스 부분에 `wplaybook-button`를 텍스트로 똑같이 입력해 주시기만 하면 됩니다.
